# 网页 PDF

用 Electron 的 webview 打开网页。页面触发的 PDF 下载，以及阅读器里已经打开的 PDF，都会进右侧列表，再另存到你指定的位置。

## 环境

- macOS
- Node.js 18 或更高

## 启动

```bash
npm install
npm start
```

## 使用

1. 在地址栏输入网址，回车打开。没写协议时会自动补上 `https://`。
2. 「历史」里是打开过的网页。再打开同一地址会把这条记录提到最前面。点一条即可重新打开，记录会保留到下次启动。
3. PDF 出现在右侧列表后：
   - **另存为**：复制到你选择的路径，列表里的副本还在。
   - **全部导出**：把已捕获的 PDF 复制到同一个文件夹。重名会自动加上序号。
   - **打开** / **显示**：用系统默认程序打开，或在访达里定位。
   - **移除** / **清空**：只删除应用目录里的副本，已经另存出去的文件不动。

地址栏聚焦快捷键是 `Command+L`（Windows / Linux 为 `Ctrl+L`）。

网页里的新窗口会用同一个会话打开，里面的 PDF 下载也会进列表。右键链接可以打开、下载或复制。

## PDF 怎么进列表

- 页面发起的下载（包括 `Content-Disposition: attachment`、`<a download>` 和脚本生成的 Blob）会直接保存，不再弹出系统保存框。
- 类型暂时看不出来的下载会先收下，再用文件头判断是不是 PDF。不是 PDF 的文件会改存到系统「下载」文件夹。
- 地址或响应类型是 PDF、但浏览器用阅读器打开的文件，会以「页面中的 PDF」出现。另存为时优先从当前页的 PDF.js 阅读器取出已经打开的内容；取不到再按原地址重新下载。需要登录的文件请保持网页处于登录状态。

捕获的文件在应用数据目录的 `captured-pdfs` 里，重启后列表还在。

## 测试

```bash
npm test
```

## 目录

| 路径 | 内容 |
| --- | --- |
| `main.js` | 窗口、下载拦截、另存为 |
| `preload.js` | 页面可用的接口 |
| `renderer/` | 地址栏、webview 和 PDF 列表 |
| `lib/` | 文件名与 PDF 判断 |
